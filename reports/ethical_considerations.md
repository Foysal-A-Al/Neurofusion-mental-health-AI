# Ethical Considerations

Mental-health prediction is sensitive and can cause harm through false reassurance, stigma, surveillance, or inappropriate intervention. This project includes research-only notices, sigmoid calibration, an explicitly heuristic probability band, and a confidence threshold. These mechanisms do not establish clinical safety or validity.

The deterioration label has no measured future-event window, and observed-pattern summaries are not model-derived explanations. Real-world evaluation would require external prospective data, a precise outcome/horizon, informed consent, privacy protection, subgroup analysis, qualified clinical oversight, and appropriate regulatory assessment. The local API does not implement authentication or patient-record storage and should be used with synthetic data.
